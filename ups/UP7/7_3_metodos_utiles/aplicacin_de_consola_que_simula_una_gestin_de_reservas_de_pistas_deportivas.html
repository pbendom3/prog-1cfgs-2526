Aplicación de consola que simula una gestión de reservas de pistas deportivas

Actividad

Las indicaciones que se dan son las siguientes:

  • Se dispone de Pistas de pádel y de tenis. Todas las pistas tienen atributos comunes, como el tipo de techado (indoor o exterior) y un identificador.
  • Cada subtipo de pista tiene atributos propios. Por ejemplo:
    • Las pistas de Tenis pueden tener superficie de tierra batida, cemento o hierba.
    • Las pistas de Pádel pueden tener paredes de cristal o de cemento.
  • Se dispone de una lista de Usuarios con nombre e id registrados en la aplicación.
  • Las Reservas incluyen: el usuario que ha reservado la pista, la pista reservada (de pádel o tenis) y la fecha-hora de la partida. Se recomienda el uso de la clase LocalDateTime para facilitar el trabajo con fechas:
LocalDateTime ejemplo = LocalDateTime.of(2026, 04, 1, 19, 50);
LocalDateTime ahora = LocalDateTime.now();

a) Dibuja un diagrama de clases UML para representar el problema.

b) Implementa las clases de tu diagrama.

c)  Implementa una función que elimine todas las reservas asociadas a pistas de un tipo concreto (pádel o pickelball), suponiendo que dispones de una lista de objetos Reserva. 

d) ¿Qué estructura de datos utilizarías para mejorar el almacenamiento de las reservas sabiendo que las búsquedas de reservas habituales se hacen por Usuario? Explica tu respuesta.

e) Implementa un método para la búsqueda de reservas por Usuario según la estructura que hayas elegido en el apartado anterior. El método debe devolver una lista con todas las reservas el usuario.

f) Implementa un método para la generación de una Reserva y su inserción a una lista -o en la estructura elegida en el apartado d)-, que lance una excepción personalizada si un Usuario ya tiene una Pista reservada en esa misma hora (conflicto de reservas). Genera también el código de la excepción.
