## :pencil: Batería de problemas (DFDs y pseudocódigos)

**Expresa los siguientes programas en forma de diagrama de flujo y pseudocódigo:**
 
1. Programa para sumar dos números leídos por teclado y escribir el resultado.
 
2. Programa que permita leer 2 números diferentes y nos diga cuál es el mayor.
 
3. Programa para sumar 100 números leídos por teclado. 
 
4. Programa en el que se almacenen 3 números introducidos por teclado en 3 variables A, B y C. El programa debe decidir cuál es el mayor y cuál es el menor.
