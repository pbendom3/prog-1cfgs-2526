## :pencil: Batería de programas sencillos en _Java_ :computer:

**:arrow_forward: Ejercicio 1**. Escribe un programa para pedirle al usuario el número de `horas` y la `tarifa por hora` para calcular el **_salario bruto_**.
 
**:arrow_forward: Ejercicio 2**. Reescribe el programa anterior para darle al empleado **_1.5_ veces** la `tarifa horaria` para todas las horas trabajadas que excedan de 40.

**:arrow_forward: Ejercicio 3**. Realizar un programa que pida un `número` al usuario, que deberá introducirlo usando el teclado. El algoritmo debe identificar si el `número` introducido se trata de un número positivo (>0) o un número negativo (<0) y controlar el caso particular del número 0, que es natural.
 
**:arrow_forward: Ejercicio 4 (hecho en DFD)**. Realizar un programa para calcular el `mínimo de 3 números` leídos desde teclado. En caso de que el usuario introduzca dos o tres números iguales, informaremos con el siguiente mensaje: "**_ERROR: hay números introducidos que son iguales_**".
 
**:arrow_forward: Ejercicio 5**. Realizar un programa para dividir `dos números` leídos por teclado y escribir el `resultado`. Se debe controlar que el `divisor` no sea igual a `0` e informaremos con el siguiente mensaje: "**_ERROR: no se puede dividir entre 0_**".
 
**:arrow_forward: Ejercicio 6**. Necesitamos realizar un programa que decida por nosotros si tenemos que ir (o no) a comprar.
 
Funcionamiento:

- El programa nos debe preguntar si tenemos `tomate`.
- El programa nos debe preguntar si tenemos `aceite`.
- El problema nos debe preguntar si tenemos `jamón`.
 
En función de las respuestas que le demos, el programa debe decidir y respondernos un mensaje que aparezca por pantalla con el siguiente texto:
 
- "**_¡Tenemos que ir a comprar!_**" en caso de que se cumpla que no tenemos alguno de los ingredientes necesarios.
- "**_¡No tenemos que ir a comprar!_**" en caso de que se cumpla que ya tenemos todos los ingredientes necesarios.
 
**:arrow_forward: Ejercicio 7**. Realiza un programa para mostrar un mensaje por pantalla que indique si un triángulo es «escaleno», «equilátero» o «isósceles» introduciendo el `tamaño de sus lados` por teclado.
